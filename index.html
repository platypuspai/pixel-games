// WHAT IS PIXEL-GAMES?

Pixel-Games is a collection of small browser games made as a school project. All games are free to play, directly in your browser.

// THE GAMES

There are currently 6 games available: Dino World, Mini Browser Platformer, One Square, Dodging Arena, Money Digger and Lucky Guy. Some games are also available as a Chrome extension.

DINO WORLD MINI PLATFORMER ONE SQUARE DODGING ARENA MONEY DIGGER LUCKY GUY

// TECHNOLOGY

All games are built with vanilla HTML, CSS, JavaScript and Python. One game is made in Scratch. No frameworks, no libraries — just pure web technology.

HTML5 CSS3 JAVASCRIPT CANVAS API PYTHON SCRATCH
