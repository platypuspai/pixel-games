ℹ INFO

// WHAT IS PLIXO-ARCADE?

Plixo-Arcade is a collection of small browser games made as a school project. All games are free to play, directly in your browser.

// THE GAMES

There are currently 10 games available: DVD+, Dino World, Mini Browser Platformer, One Square, Dodging Arena, Bug Escape, Money Digger, Lucky Guy, Mini Apocalypse and Time Ticker. All games are playable directly in your browser.

DVD+ DINO WORLD MINI PLATFORMER ONE SQUARE DODGING ARENA BUG ESCAPE MONEY DIGGER LUCKY GUY Mini Apocalypse TIME TICKER

// TECHNOLOGY

All games are built with vanilla HTML, CSS, JavaScript and Python. One game is made in Scratch. No frameworks, no libraries — just pure web technology.
